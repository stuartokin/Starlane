❓ How do I get a Gemini API key?
  1. Go to Google AI Studio → API keys ↗ and sign in with a Google account.
  2. Choose Create API key, then copy it and paste it in the box above.
  3. There is a free tier with daily limits, which is plenty for a few banks. Google’s pricing page ↗ has the details.

Your key stays on this device and is only sent to Google. The model box can stay as it is; other model names are on Google’s models page ↗. No key? Use 📖 The bank kit above instead: it works with the free chat in Gemini ↗, ChatGPT ↗ or Claude ↗, with no key needed.
